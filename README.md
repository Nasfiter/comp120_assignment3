## About: COMP 120 GITHUB practise

By completing this assignment, students will:
1.	Create and manage a project on GitLab/GitHub.
2.	Use milestones to track progress.
3.	Create and assign issues.
4.	Clone repositories and contribute via branches.
5.	Manage collaborator access.

## Usage

To get a local copy of this repository, make sure Git is installed and run:

```sh
git clone https://github.com/Nasfiter/comp120_assignment3.git
cd comp120_assignment3
```

To contribute, create a branch, make your changes, then commit and push them:

```sh
git switch -c my-change
git add .
git commit -m "Describe your change"
git push -u origin my-change
```

After pushing, open a pull request on GitHub to propose your changes.
